# Anita Jewellery — Customer App

The customer Android app for **Anita Jewellery** (Thoubal, Manipur): browse the
collection, save favourites, and book on WhatsApp. Home to home since 2009.

- App package: `com.anitajewellery.shop`
- Releases on this repo carry the signed APK (also linked from the website).
- The **Emulator screenshots** workflow (Actions tab) installs the latest
  release on a cloud Android 14 emulator, walks the whole customer journey
  and publishes screenshots to the `emulator-screenshots` branch.

Shop: https://anitajewellery.github.io
